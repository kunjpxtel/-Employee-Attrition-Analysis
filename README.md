# Project Purpose
Employee attrition is a significant challenge for organisations, leading to increased recruitment costs, loss of experienced talent, and reduced productivity. This project analyses HR employee data to identify the key factors influencing employee turnover and presents the findings through an interactive Tableau dashboard.

The objective is to help HR professionals understand workforce trends, identify high-risk employee groups, and support data-driven retention strategies.

# Project Architecture

HR Dataset (CSV) > Data Cleaning & Preparation > Exploratory Data Analysis > KPI Calculation > Tableau Dashboard > Business Insights

# Project Overview
This project performs an in-depth analysis of employee attrition using an HR Analytics dataset. The raw employee data is cleaned, processed, and analysed to uncover patterns contributing to employee turnover.

The processed dataset is then used to create an interactive Tableau dashboard that visualises key HR metrics, including employee demographics, department-wise attrition, salary distribution, job satisfaction, overtime impact, and overall attrition rate.

The dashboard enables HR managers and business stakeholders to explore employee trends interactively and make informed decisions to improve employee retention.
